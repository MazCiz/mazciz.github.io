I build and optimize the backend systems products run on — APIs, data, and the pipelines that ship them — then help keep them fast and healthy in production.

process/

01

Understand

Map the problem, constraints and data before writing a line of code — requirements, edge cases, and what 'done' actually means.

02

Design

Shape the data model, API contracts and service boundaries. The decisions that are cheap now and expensive later get made here.

03

Build

Implement clean, tested services and APIs — readable code the next person (often future me) can change without fear.

04

Ship

Containerize, wire up CI/CD and deploy. Getting it to production reliably is part of the job, not an afterthought.

05

Improve

Instrument with metrics, watch it in production, and optimize. Software isn't finished at launch.

Quantum Wallet

Post-quantum crypto wallet

›

A crypto wallet where account ownership is proven by post-quantum ML-DSA-65 signatures instead of ECDSA — so it stays secure once quantum computers can forge today's keys. Features a legacy-to-post-quantum migration flow and an on-chain key-exposure check that flags whether an address is already vulnerable. All cryptography runs client-side (ML-DSA/ML-KEM via @noble), keys never leave the browser, and the wallet is non-custodial. A single seed derives every key, sealed at rest with scrypt + AES-256-GCM.
