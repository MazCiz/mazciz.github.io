CoilCRM↗

A CRM that speaks HVAC. Sites, equipment, and service jobs in a workflow built around the contractor’s day.

Next.jsTypeScriptReactPrisma
Behind the build +

A lightweight, industry-specific CRM for a single trade: commercial HVAC contractors. Instead of a general-purpose CRM's generic Accounts and Opportunities you spend a week configuring, the data model is already HVAC-shaped — Sites (the buildings you service), Equipment tracked with contract status, and Service Jobs moving through a pre-built pipeline (New Lead → Site Survey → Quote Sent → Won → Scheduled). 03 / DATA & ANALYSIS

StratForge↗

From a trading idea to a testable strategy. A Python engine with realistic fills, risk metrics, and interactive charts.

PythonpandasJavaScriptBacktesting
Behind the build +

A strategy backtester and paper-forward tester for gold and NASDAQ, re-engineered from an AI trading app. A long/short engine marks positions to market with next-bar-open fills (no lookahead) and adverse slippage/commission modelling, reporting Sharpe, max drawdown, win rate and an equity curve. Strategies can be hand-built, swept across a parameter grid, or generated from plain English by Claude — structured outputs constrain the model to a real feature vocabulary, then every candidate has to survive the same backtest. Ships a dependency-free local web app (candlestick charts with trade markers, live parameter controls, a strategy leaderboard) plus an intraday 15-minute opening-range-breakout study that isolated a volume-confirmation edge holding across both markets. Python engine, yfinance data, vanilla-JS canvas UI.

04Quantum WalletPost-quantum crypto wallet+

A crypto wallet where account ownership is proven by post-quantum ML-DSA-65 signatures instead of ECDSA — so it stays secure once quantum computers can forge today's keys. Features a legacy-to-post-quantum migration flow and an on-chain key-exposure check that flags whether an address is already vulnerable. All cryptography runs client-side (ML-DSA/ML-KEM via @noble), keys never leave the browser, and the wallet is non-custodial. A single seed derives every key, sealed at rest with scrypt + AES-256-GCM.

Next.jsTypeScriptCryptographyPost-QuantumTailwind
05ghostNoteServerless P2P encrypted chat+

A peer-to-peer, end-to-end encrypted terminal chat for a small circle of friends — no server to host and no sign-up; your identity is just a keypair. Direct messages and invite-code group rooms travel over a DHT (Hyperswarm), with a hybrid post-quantum key exchange (X25519 + ML-KEM-768) layered on the Noise transport, so recorded traffic stays private even against a future quantum adversary. Chat history is stored on-device encrypted at rest (ChaCha20-Poly1305 under an identity-derived key); messages to an offline friend queue locally and deliver on reconnect, and groups gossip-relay so everyone stays in sync without a hub. Ships as a full-screen terminal UI with per-identity colors, installable straight from the repo.

06UIBlockerDeclutter any site · browser extension+

A browser extension that hides any UI element on any website — like an adblocker, but for the features you never use. A point-and-click element picker generates a resilient CSS selector (favouring ids, data-/aria-attributes and non-hashed class names, with positional fallbacks), then injects a style rule so the element stays gone on every visit — including content that single-page apps load later. Nothing is ever deleted: every rule is reversible, with per-element show/hide, a per-site master switch, and a toolbar badge counting what's hidden. Rules live per-domain in chrome.storage and export/import as JSON for shareable 'declutter profiles'. Manifest V3, with on-demand content-script injection so it works even on already-open tabs.
